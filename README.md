# GO_Project

Домашние задания по дисциплине **«Язык Go»**.

## Домашняя работа 1. Введение в Go

Программа:

- выводит имя пользователя из переменной окружения `USER` (или `USERNAME` в Windows);
- считывает и выводит аргументы командной строки;
- показывает текущую версию Go с помощью `runtime.Version()`.

## Требования

- Go 1.22 или новее.

## Запуск

```bash
go run . arg1 arg2
```

Пример вывода:

```text
Имя пользователя: alexandra
Аргументы CLI: [arg1 arg2]
Версия Go: go1.22.0
```

Фактические имя пользователя и версия Go зависят от окружения, в котором запускается программа.
