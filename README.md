# GO_Project

Домашние задания по дисциплине **«Язык Go»**. Требуется Go 1.22 или новее.

## Структура репозитория

```text
.
├── main.go        # ДЗ 1: имя пользователя, CLI-аргументы, версия Go
├── go.mod
├── gateway/       # ДЗ 2: HTTP-шлюз (отдельный Go-модуль)
└── ledger/        # ДЗ 2: бизнес-логика транзакций (отдельный Go-модуль)
```

## ДЗ 1. Введение в Go

```bash
go run . arg1 arg2
```

## ДЗ 2. Функции: Gateway и Ledger

### Gateway

HTTP-сервер на порту 8080, маршрут `GET /ping` возвращает `pong`.

```bash
cd gateway
go run .
```

Проверка в другом терминале:

```bash
curl -i http://localhost:8080/ping
```

Ожидаемый ответ: статус `200 OK` и тело `pong`.

### Ledger

Структура `Transaction` (ID, Amount, Category, Description, Date), хранилище в памяти, функции `AddTransaction` и `ListTransactions`. `AddTransaction` возвращает ошибку при нулевой сумме или пустой категории. В `main` добавляются тестовые транзакции и выводится их список.

```bash
cd ledger
go run .
```

Ожидаемый вывод:

```text
Ledger service started
Ошибка добавления транзакции (Некорректная транзакция): сумма транзакции не может быть равна нулю
Список транзакций:
ID=1 | Сумма=-1500.50 | Категория=Продукты | Описание=Покупка продуктов в магазине | Дата=2026-10-01
ID=2 | Сумма=85000.00 | Категория=Зарплата | Описание=Зарплата за сентябрь | Дата=2026-10-02
ID=3 | Сумма=-450.00 | Категория=Транспорт | Описание=Проездной на метро | Дата=2026-10-03
```
